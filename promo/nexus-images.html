Chef Hand-off for MDL3
How the hand-off works
MDL3 keeps the game's boot. A tiny addon hands the game to Chef 6 seconds in.
1
0 s
MDL3 runs the game's boot and starts its addons, Chef Hand-off among them.
2
≈ 5 s
Chef Hand-off reads the game's patch files and finds the addons made for Chef (91 files in 5 ms in one real run).
3
6 s
It hands the game to Chef, with the hand-off that Chef's own documentation describes for other loaders.
4
then
MDL3 keeps running its mods. Chef runs its mods: HUDdle, Treasure Radar and the rest.
Nothing of Chef, HUDdle or MDL3 is included or changedLua only, no DLLsDoes nothing if Chef is missing or already running

How 0.2.0 tells
Before the hand-off it reads the game's patch files. An addon counts as made for Chef if it has a line that starts with local chef = ... or a -- HD2-Requires: chef-shared-loader header line. Those are taken off package.loaded, so Chef starts them properly.
