# Chef Hand-off for MDL3 0.2.0

让 **Chef Shared Loader**（以及只能在它下面运行的 mod，比如 HUDdle、Treasure Radar）和 **MDL3**（以及 BF5 击杀反馈这类 MDL3 mod）在同一个 Helldivers 2 里一起工作。
这个 mod 由 MDL3 启动，进游戏 6 秒后用 Chef 文档里写明的办法把游戏交给 Chef。没装 Chef，或者 Chef 已经在运行时，它什么也不做。

## 安装

1. 下载下面的 `Chef-Hand-off-for-MDL3-0.2.0.zip`，加进 Arsenal / HD2 Mod Manager 并启用。你已经有：MDL3、Chef Shared Loader（1.2.0 以上）和要用的 mod。
2. **MDL3 的优先级要比 Chef 高**（游戏运行的 boot 必须是 MDL3 的）。Arsenal 里：设置是 *First mod highest priority* 就把 MDL3 放在 Chef 上面，是 *Last mod highest priority* 就放在下面。
3. Purge，再 Deploy。启动游戏，在标题画面停 10 秒以上，再进一局任务。

成功的样子、各种现象怎么判断、要附哪些日志：见仓库里的 `handoff/README.md`。

## 0.2.0 的变化

修了 Treasure Radar 这类 Chef mod 不运行的问题：MDL3 会把所有带 `HD2-Addon` 头的 Lua 都"启动"一遍，Treasure Radar 没报错，Chef 就当它已经被别的加载器启动而跳过。
现在交接前先读游戏的补丁文件，找出做给 Chef 的 addon（行首有 `local chef = ...`，或者有 `-- HD2-Requires: chef-shared-loader` 头行），把它们从 `package.loaded` 里摘掉，Chef 就正常启动它们。

## 真机验证

作者的游戏：MDL3 3.0.0-dev.29，Chef Shared Loader 1.4.1，HUDdle 0.6.11，Treasure Radar 0.7.1n，BF5 击杀反馈 MDL3 版 2.0.1。

- 交接成功，HUDdle 正常，正常结算回飞船没问题（0.1.0 的日志）。
- 0.2.0：Treasure Radar 起来了，BF5 反馈正常，ESC 回飞船没有闪退（作者的试玩报告）。`chef_handoff.log`：`patch files read: 91 (4 addons, 2 made for Chef, 0 read errors) in 5 ms`，认出的是 Treasure Radar 和 HUDdle。

## 已知的问题

- 0.1.0 下任务中按 ESC 回飞船闪退过**一次**，原因没找到，之后没有再出现（0.2.0 没有做针对它的改动）。再出现的话，请先把 `MDL.log` 拷出来再重开游戏，连同 `chef_handoff.log`、`chef_loader.log` 一起反馈。
- 只在 MDL3 3.0.0-dev.29（"protected preview"）上测过。

## English

Helldivers 2 runs only one `boot`, so Chef Shared Loader and MDL3 normally cannot both work, and Chef-only mods (HUDdle, Treasure Radar) have no MDL3 version.
This addon is started by MDL3 and, 6 seconds into the game, hands the game over to the real Chef with the hand-off Chef's own documentation describes for other loaders.
Install the zip below, enable it, and give **MDL3 a higher priority than Chef**, then Purge and Deploy. 0.2.0 fixes Chef mods that MDL3 had already "started" without Chef (Treasure Radar) being skipped by Chef.
Tested in the real game by the repository owner (MDL3 3.0.0-dev.29, Chef 1.4.1). No code of Chef, HUDdle or MDL3 is included. MIT license.
