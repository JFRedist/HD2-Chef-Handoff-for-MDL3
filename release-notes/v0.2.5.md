# Chef Hand-off for MDL3 0.2.5

让 **Chef Shared Loader**（以及 HUDdle、Treasure Radar、NarrowHUD 等只能在它下面运行的 mod）和 **MDL3**（以及 BF5 击杀反馈这类 MDL3 mod）在同一个 Helldivers 2 里一起工作：这个 mod 由 MDL3 启动，进游戏 6 秒后用 Chef 文档里写明的办法把游戏交给 Chef。

## 和 0.2.4 比

- **Rat's Shared Loader 的 mod（HD2 Transmog）不再被跳过。** Rat 放在 MDL3 下面（不要放最高）：交接以后 Chef 把 Rat 当作一个 boot 脚本拉起来，Rat 再启动标了 `-- @loader rat` 的 mod。0.2.4 下 Transmog 没有运行：MDL3 先“启动”它失败，`require` 在 `package.loaded` 里留下一个占位，Rat 把它当作别人已经启动过。0.2.5 在交接前把这些 mod 的失败占位拿掉。
- **补丁文件超过 400 个时也读完。** 0.2.4 及以前，找 Chef mod 的扫描最多读到 `patch_400`；400 号以后、MDL3“启动”时没报错的 Chef mod（像 Treasure Radar 0.7.1）会被 Chef 跳过。现在读到连续 8 个号码都不存在为止。
- 别的行为和 0.2.4 一样。

## 安装

1. 下载下面的 `Chef-Hand-off-for-MDL3-0.2.5.zip`，加进 Arsenal / HD2 Mod Manager 并启用（替换旧版本）。你已经有：MDL3、Chef Shared Loader（1.2.0 以上）和要用的 mod。
2. **MDL3 的优先级要比 Chef 高**（游戏运行的 boot 必须是 MDL3 的）。用 Rat's Shared Loader 的话，Rat 也放在 MDL3 下面。
3. **本 mod 放在最低优先级。**
4. Purge，再 Deploy。启动游戏，在标题画面停 10 秒以上，再进一局任务。

成功的样子：`%APPDATA%\Arrowhead\Helldivers2\chef_handoff.log` 里有 `Chef Shared Loader ... started`，`chef_loader.log` 里有 `started by MDL3 chef_handoff 0.2.5, which handed off to me`。装了 Rat 的话，`chef_handoff.log` 里还有一行 `made for Rat's Shared Loader: ...`。

## 已知的问题

- 用 Rat 时，Chef 的 F9 里 Rat 运行的 mod 写的是 “Run by MDL3 chef_handoff”；Rat 的加载画面会显示 READY WITH WARNINGS（它要求放最高）；Rat 的回调在 Chef 的卡死看门狗下面。
- MDL3 3.0.0-dev.33 只看前 512 个补丁文件：补丁文件一多于 512，跟 MDL3 一起放在最高的 HD2 Data Hub 就不会被 MDL3 启动，依赖它的 MDL3 mod 都不运行。这要 MDL3 修。

## 验证到了哪一步

- **自写测试** 130 项；**Chef 自带的模拟器**（真实的 Chef 1.4.1 和 1.5.1）86 项，加真实的 HUDdle 0.6.11 是 90 项：全过。
- 用作者游戏里真实的补丁文件（Rat 1.0.1、Transmog 1.1.2），照 0.2.4 那次 MDL3 留下的样子：0.2.5 认出 Transmog、通知模块和运行库是 Rat 的，拿掉前两个的失败占位。
- **真机**：0.2.5 还没在游戏里跑过。

反馈问题时请附上 `chef_handoff.log`、`chef_loader.log` 和 `MDL.log`（`MDL.log` 每次启动会被覆盖，先拷出来再重开游戏）；用 Rat 的话再加 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\SharedLoader-loader.log`。

## English

0.2.5 lets Rat's Shared Loader start its mods (HD2 Transmog) here: keep Rat below MDL3, and Chef runs Rat as one of its boot scripts after the hand-off. With 0.2.4 Rat skipped Transmog, because MDL3 had tried to start it first and require's placeholder was left in package.loaded; 0.2.5 takes that placeholder off for mods marked `-- @loader rat`. It also reads every patch file when there are more than 400 (0.2.4 stopped at patch_400).
Install: add the zip below to your mod manager and enable it, give **MDL3 a higher priority than Chef** (and than Rat, if you use it), give **this mod the lowest priority**, then Purge and Deploy.
Verified with 130 checks of its own and 86 in Chef's simulator with the real Chef 1.4.1 and 1.5.1 (90 with the real HUDdle), and against the real Rat 1.0.1 and Transmog 1.1.2 patch files; not yet run in the real game. MIT license.
